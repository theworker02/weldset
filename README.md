# weldset

Weld HTML/Markdown set fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/weldset/

## Install / run

```bash
git clone https://github.com/theworker02/weldset.git
cd weldset
node src/cli.js
node --test
```
